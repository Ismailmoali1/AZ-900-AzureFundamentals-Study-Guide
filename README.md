## How to Study for AZ-900

### Step 1: Get to Know the Exam Style
- AZ-900 tests **concepts**, not deep technical skill
- Concentrate on:
  - Identifying services
  - Knowing what each one is used for
  - Picking the *best Azure solution* for a scenario

---

### Step 2: Start With Practice Questions
- Work through **100–200 practice questions**
- Pay attention to:
  - Why the right answer is correct
  - Why the other options are not

Doing this builds **pattern recognition**, which is the key skill for AZ-900.

---

### Step 3: Watch a Crash-Course Video
- Put on a **2–4 hour tutorial (at 1.25x–1.5x speed)**
- Pay particular attention to:
  - Service models (IaaS, PaaS, SaaS)
  - Core Azure services
  - Governance tools
  - Networking fundamentals

---

### Step 4: Zero In on High-Yield Concepts

#### Service Models
- IaaS → You handle the OS
- PaaS → Azure handles the OS
- SaaS → You simply use the software

#### Governance
- RBAC → Controls who has access
- Policy → Controls what is permitted
- Locks → Stop resources from being deleted

#### Architecture
- Region → a geographic location
- Availability Zone → redundancy across datacenters
- Resource Group → a container that holds resources

#### Monitoring
- Azure Monitor → logs and metrics
- Azure Advisor → recommendations
- Service Health → Azure outage information

#### Identity
- Microsoft Entra ID → identity management
- MFA → an added layer of security
- SSO → one login for everything

---

### Step 5: Wrap Up With a Final Review
- Revisit the areas where you're weakest
- Answer 20–30 more questions
- Spend your time on **the confusing topics only**

## Exam Strategy

- Don't overthink the easy questions  
- Rule out 2 incorrect answers  
- Go with the most **Azure-native / managed option**  

When you're stuck:
> Answer → Flag → Move on → Return later

## ⚠️ Important Note

This study method comes from a **2-day preparation plan** and assumes that you have:

- A basic understanding of cloud concepts
- Some prior contact with Azure services or terminology
- Ease with learning through practice questions

If you're brand new to the cloud, this may NOT be enough.

### Recommended Approach for Beginners
- Set aside **6–8 days (or longer)** to prepare
- Work through the **Microsoft Learn modules**
- Follow full-length tutorials at a slower speed
- Practice regularly before booking the exam

This guide works best for:
- Quick revision
- Fast-track preparation
- Strengthening knowledge you already have
